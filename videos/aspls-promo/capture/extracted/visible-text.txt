[h1] aspls
[strong] Answer Set Programming for VS Code, Cursor, and VSCodium
[p] Language intelligence + Clingo runner in one extension · ASP-Core-2 /
[a] Clingo
[strong] Install on VS Marketplace
[strong] Install on Open VSX
[strong] Report issue
[strong] aspls
[p] is a VS Code / Cursor / VSCodium extension for
[strong] Answer Set Programming
[p] in the ASP-Core-2 /
[a] Clingo
[p] dialect. It combines
[strong] language intelligence
[p] (diagnostics, completion, hover, go-to-definition, find-references, semantic + rainbow highlighting) with a
[strong] Clingo runner
[p] (bundled WASM or PATH binary, Solver sidebar) — so you do not need a highlight-only extension plus a separate run tool.
[p] Works with
[code] .lp
[p] and
[code] .asp
[p] files.
[h2] Screenshots
[h3] Semantic highlighting
[p] Facts, rule heads, negation, and directives each get distinct colors. Optional rainbow underlines keep predicate names visually distinct across a file.
[h3] ASP Solver sidebar
[p] Run Clingo from the editor title bar or the
[strong] ASP → Solver
[p] view. Answer sets, errors, and re-run controls stay in the sidebar;
[strong] Controls
[p] persist models, native Clingo path, and additional files.
[h3] Architecture
[p] The TypeScript extension hosts the Clingo runner and UI; a Python LSP server provides parsing and IDE features. Both share the same file
[strong] pool
[p] via
[code] aspls.clingo.json
